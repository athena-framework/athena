## [0.5.0] - 2026-10-18

### Changed

- **Breaking:** Raise an error if a command receives more arguments than it expects ([#734]) (George Dietrich) <!-- blacksmoke16 -->
- Add `ACON::Bundle` to integrate the component with the DI component, and an `ACON::Application` constructor that runs the commands registered within a service container ([#756]) (George Dietrich) <!-- blacksmoke16 -->

### Added

- Add improved sub-command support ([#735]) (George Dietrich) <!-- blacksmoke16 -->
- Display command, option, and value descriptions in `fish` shell completion ([#750]) (George Dietrich) <!-- blacksmoke16 -->

### Fixed

- Exit with `ACON::Command::Status::FAILURE` instead of `SUCCESS` when a caught `ACON::Exception` has no positive `code` ([#726]) (Damián Búho) <!-- damian-buho -->
- Treat a non-integer `SHELL_VERBOSITY` as `0` instead of raising ([#727]) (Damián Búho) <!-- damian-buho -->
- Fix input forwarding for `PROGRAM_NAME` based commands ([#736]) (George Dietrich) <!-- blacksmoke16 -->
- Fix horizontal table top border is incorrectly rendered ([#743]) (George Dietrich) <!-- blacksmoke16 -->
- Fix table borders around colspan cells and header-less tables ([#743]) (George Dietrich) <!-- blacksmoke16 -->
- Fix `bash` and `fish` shell completion of `--option=value` style option values ([#750]) (George Dietrich) <!-- blacksmoke16 -->
- Fix shell completion running command substitutions in `zsh`, not working with aliases or `SHELL_VERBOSITY=-1`, and mishandling `\E` in `bash` ([#750]) (George Dietrich) <!-- blacksmoke16 -->
